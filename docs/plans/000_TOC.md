## Status words (exactly these three, nothing else)

| Status | Meaning |
|---|---|
| `Not Implemented` | No part of the plan's acceptance criteria has passed with evidence. |
| `Partially Implemented` | Some steps are done and verified; at least one acceptance criterion is still open. |
| `Implemented` | Every acceptance criterion passed, the evidence is archived, and the orchestrator verified it independently (AGENTS.md §10, Zero-Trust Audit Rule). A builder's own claim never sets this status. |

Only the orchestrator changes a status, and only after verification. Mapping to `ORCHESTRATOR.md` ledger words: `Not Implemented` = `NOT_BUILT`, `Partially Implemented` = `PARTIALLY_BUILT`, `Implemented` = `BUILT`.

## Plan file naming

`NNN_snake_case_name.md`, three digits, in `docs/plans/`. Numbers follow build order. Numbers are never reused. A new plan takes the next free number; if it must run earlier, its `Depends on` says so.
